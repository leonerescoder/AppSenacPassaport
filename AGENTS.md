# Agents
Este projeto é um passaport virtual de um evento que é realizado em uma escola. Os visitantes poderão encontrar as oficinas e horarios e escolher participar. O aplicativo deve registrar as oficinas que um visitante participou (concluiu) e gerar um relatorio administrativo.

Este é um projeto feito em **React** usando **Vite** na versão mais recentes,Ele faz uso do banco de dados do **Supabase** e a usa API.
